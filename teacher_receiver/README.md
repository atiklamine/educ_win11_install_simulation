# برنامج مستقبل تقارير المحاكي التعليمي (ReportReceiver.exe)
### خادم الاستقبال التلقائي للتقارير وتصنيف نتائج التلاميذ عبر الشبكة المحلية (LAN)

---

## 1. نظرة عامة
برنامج **مستقبل التقارير** (`ReportReceiver.exe`) هو تطبيق أصيل وخفيف جداً (حجمه **48 كيلوبايت فقط**) مخصص لحاسوب الأستاذ.
يعمل التطبيق كخادم استلام محلي عالي السرعة يستقبل تقارير تقييم الكفاءة (بصيغة PDF) الصادرة تلقائياً من محاكي التلميذ (`Win11_Edu_Simulator.exe`) فور نقر التلميذ على "استخراج وثيقة التقييم".

---

## 2. المزايا الرئيسية
1. **صفر إعدادات أو برامج على جهاز التلميذ:** التلميذ يشغل المحاكي التعليمي فقط.
2. **اتصال فوري وآمن (Outbound TCP/HTTP):** لا يتطلب أي صلاحيات مسؤول على أجهزة التلاميذ ولا يتعارض مع جدار حماية ويندوز.
3. **منع التكرار الصارم (Strict Anti-Duplicate):** يرفض الخادم استلام نفس التقرير مرتين إذا لم يطرأ أي تغيير على العلامة أو المحتوى (بصمة SHA-256 متطابقة).
4. **إدارة الإصدارات المتطورة (`_v2`, `_v3`):** إذا أعاد التلميذ المحاكاة وحقق إنجازاً أو علامة جديدة، يتم حفظ المحاولة الجديدة بوسم الإصدار دون مسح محاولته السابقة.
5. **شجرة المجلدات وفق التوقيت المدرسي الجزائري:**
   `المسار الأساسي \ [اسم الفوج] \ [تاريخ الحصة YYYY-MM-DD] \ [توقيت الحصة] \ [اسم_الملف.pdf]`
   - الفترة الصباحية: ساعات كاملة (`08h00-09h00`, `09h00-10h00`, `10h00-11h00`, `11h00-12h00`).
   - الفترة المسائية: أنصاف ساعات تبدأ من 13:30 (`13h30-14h30`, `14h30-15h30`, `15h30-16h30`, `16h30-17h30`).
6. **لوحة الصدارة والترتيب البيداغوجي المباشر:**
   ترتيب التلاميذ وفق معيار الأستاذ المعتمد:
   $$\mathbf{الفوج \;\longrightarrow\; العلامة (\downarrow تنازلياً) \;\longrightarrow\; الوقت المستغرق (\uparrow تصاعدياً الأسرع أولاً) \;\longrightarrow\; اللقب والاسم}$$
7. **التوليد التلقائي لملف كشف الحصة العام (`00_ترتيب_نتائج_الحصة.html`):**
   ينشئ ويحدث البرنامج صفحة HTML أنيقة داخل مجلد كل حصة تتضمن الميداليات (🥇 ذهبية، 🥈 فضية، 🥉 برونزية)، إحصائيات القسم، وروابط فورية لفتح ملف كل تلميذ، مع جاهزية تامة للطباعة على ورق A4 (`Ctrl+P`).

---

## 3. طريقة التشغيل
1. افتح برنامج `ReportReceiver.exe` على حاسوب الأستاذ قبل بدء الحصة أو أثناءها.
2. يظهر في الشريط العلوي عنوان IP الخاص بحاسوب الأستاذ (مثلاً `192.168.1.10`) والمنفذ (`8888`).
3. تأكد من إدراج عنوان IP هذا في نافذة إعدادات الأستاذ (`Ctrl+Shift+S`) في المحاكي، ثم احفظ الإعدادات لتتولى حزمها تلقائياً داخل `inf.dll`.
4. عند توزيع مجلد المحاكي على أجهزة التلاميذ، سيتصل المحاكي آلياً بالخادم فور استخراج التقرير.

---

## 4. إعادة البناء والتطوير
لإعادة بناء البرنامج من المصدر عبر مترجم C# المدمج في ويندوز:
```cmd
build.bat
```
ينتج مباشرة الملف التنفيذي المحمول المستقل `ReportReceiver.exe`.
