## 📌 نبذة عن المشروع (About The Project)

برمجية تعليمية تفاعلية ثنائية الأبعاد (Pure 2D) فائقة الخفة، صُممت خصيصاً لمخابر مادة **الإعلام الآلي** بالثانويات الجزائرية وفق منهاج **السنة الأولى ثانوي (1AS - جذع مشترك علوم وتكنولوجيا / جذع مشترك آداب)**، وضمن مقاربة التدريس بالكفاءات (Competency-Based Approach).

تهدف البرمجية إلى تمكين التلميذ من خوض التجربة الكاملة لتثبيت وتهيئة نظام التشغيل **Windows 11** من الصفر وحتى سطح المكتب، مع محاكاة إعدادات البيوس UEFI الحديثة وتأمين الخصوصية الرقمية وإدارة الأقراص، دون تعريض عتاد المخبر الحقيقي لأي خطر.

## 🚀 طرق الاستخدام والتشغيل (How to Run)

تم تصميم هذا المشروع ليعمل بطريقتين مرنتين تناسبان كافة ظروف المدارس والمستخدمين:

### 1️⃣ التشغيل المباشر عبر المتصفح (Online - دون تحميل أي برامج)
يمكن للأساتذة والتلاميذ تشغيل المحاكي التفاعلي كاملاً فوراً وبضغطة زر مباشرة عبر المتصفح (Chrome, Edge, Firefox, Safari) على أي حاسوب أو جهاز لوحي دون الحاجة لتحميل ملفات `.exe`:

🔗 **[اضغط هنا لتشغيل المحاكي مباشرة عبر الويب](https://hadjaissainformatique.github.io/simu-win11-dz/)**  
*(ملاحظة: استبدل الرابط برابط حسابك على GitHub بعد النشر)*

---

### 2️⃣ التشغيل في مخابر الإعلام الآلي دون إنترنت (Offline Standalone EXEs)
للمؤسسات والمخابر غير المتصلة بشبكة الإنترنت، تتوفر نسخ تنفيذية محمولة كاملة (Portable Standalone) لا تتطلب تثبيتاً:

* 📥 **[تحميل حزمة المحاكي من قسم الإصدارات (GitHub Releases)](../../releases)**:
  * **`Win11_Edu_Simulator_x64.exe`** (~62 ميغابايت): للأجهزة الحديثة بمعمارية 64-بت.
  * **`Win11_Edu_Simulator_ia32.exe`** (~59 ميغابايت): للأجهزة القديمة بمعمارية 32-بت (Pentium / Celeron / Windows 7/8/10).
  * **`Auto_Launcher.exe`** أو **`تشغيل_المحاكي_تلقائيا.exe`** (~5 كيلوبايت): أداة ذكية تكتشف نوع نظام التشغيل وتشغل النسخة المتوافقة تلقائياً.

## 🎯 المراحل التعليمية الثمانية (The 8 Pedagogical Phases)

| المرحلة | اسم المحطة التعليمية | الكفاءة المستهدفة والمعارف المجندة |
| :---: | :--- | :--- |
| **01** | **تجهيز محطة العمل ووسائط التثبيت** | التمييز بين وسائط التخزين، توصيل منفذ USB، والتعرف على شاشة الاختبار الذاتي POST. |
| **02** | **إعداد واجهة البيوس الحديثة (Aptio UEFI)** | مقاطعة الإقلاع عبر المفتاح المناسب، ضبط ترتيب الإقلاع (Boot Priority)، وتفعيل TPM 2.0 و Secure Boot. |
| **03** | **الخيارات الإقليمية واللغوية** | ضبط لغة العرض، تنسيق الوقت والعملة الجزائري، ولوحة المفاتيح (عربية 101/102 وفرنسية AZERTY). |
| **04** | **تحديد نسخة النظام المتوافقة** | المقارنة بين نسخ Windows 11 وتحديد متطلبات العتاد (Windows 11 Pro/Education). |
| **05** | **التجزئة المنطقية ونظم الملفات** | التمييز بين MBR و GPT، تقسيم الأقراص، والتهيئة الإلزامية بنظام الملفات NTFS للقسم C. |
| **06** | **التثبيت المرحلي ونقل ملفات النظام** | استيعاب مراحل التثبيت التلقائي (نسخ الملفات، تجهيز الميزات، وإعادة التشغيل المنفصلة). |
| **07** | **تجربة الاستخدام وتأمين الخصوصية (OOBE)** | إنشاء حساب محلي مستقل للمخبر، وإلغاء تفعيل كافة خيارات التتبع السبعة لحماية الخصوصية الرقمية. |
| **08** | **سطح المكتب والإقلاع المستقل النظيف** | واجهة Windows 11 الأصلية (خلفية Bloom، شريط المهام الأكريليكي الممركز، وقائمة ابدأ)، مع تنفيذ دورة إقلاع ذاتية مستقلة من SSD. |

## ✨ ميزات بيداغوجية وتنظيمية متقدمة (Advanced Features)

### 🔒 1. إدارة الإعدادات المشفرة للأستاذ (`inf.dll`)
* تخزين مشفر بالكامل بخوارزمية **AES-256-CBC** عبر مفتاح تأمين رقمي.
* حماية لوحة تحكم الأستاذ بكلمة مرور قابلة للتغيير.
* إمكانية ضبط وتخصيص:
  * اسم المؤسسة التعليمية (الثانوية).
  * الموسم الدراسي (مثلاً: 2025/2026).
  * اسم الأستاذ المشرف.
  * قائمة الأفواج المخصصة (مثل: 1AS-01، 1AS-02...).
  * تفعيل أو تعطيل خيار "نمط الحصة" في واجهة التلميذ.
  * إلزامية كتابة أسماء التلاميذ باللغة الفرنسية/اللاتينية.

### 🔠 2. التحقق من أسماء التلاميذ باللغة الفرنسية (French Names Validation)
* ضمان توافق أسماء التلاميذ مع أنظمة التمدرس الرقمية وسهولة الفرز الإداري.
* قبول الحروف اللاتينية والفرنسية مع علامات النبر والتشكيل (`é, è, ê, ë, à, â, î, ï, ô, ù, û, ç, æ, œ`).
* تنبيه فوري ومرئي عند محاولة الكتابة باللغة العربية أو استخدام أرقام ورموز غير مقبولة.

### 📄 3. شهادة تقييم الكفاءة الرسمية (PDF Export)
* تقرير رسمي فائق الدقة A4 يحمل الترويسة الرسمية لـ **الجمهورية الجزائرية الديمقراطية الشعبية - وزارة التربية الوطنية**.
* تقييم دقيق مقسم على 4 كفاءات محورية (5.00 نقاط لكل كفاءة = المجموع /20.00).
* بطاقات متجاورة لعرض العلامة والزمن المستغرق لحسم حالات التساوي (Tie-breaker).
* جدول تفصيلي بالأخطاء الإجرائية والمفاهيمية مع التبرير العلمي البيداغوجي.
* **تسمية تلقائية معيارية للملفات** للفرز الفوري داخل مجلد الأستاذ:  
  `[group]_[grade]_[time]_[lastname]_[firstname].pdf`  
  *(مثال: `1AS-01_18.50_00-14-32_BENALI_Yacine.pdf`)*

### 🌓 4. دعم الوضعين الفاتح والمظلم (Light / Dark Mode)
* تبديل فوري للمظهر بضغطة زر من شريط التحكم العلوي (HUD).
* استخدام متغيرات تصميمية متناسقة (CSS Design Tokens) ملائمة لإضاءة مخابر الإعلام الآلي.
* حفظ التفضيل تلقائياً في الذاكرة المحلية (`localStorage`).

## 💻 التطوير والتشغيل المحلي (Local Development)

### المتطلبات الأساسية
* مثبت [Node.js](https://nodejs.org/) (الإصدار 16 أو أحدث).

### خطوات التشغيل
1. **استنساخ المستودع (Clone Repository):**
   ```bash
   git clone https://github.com/hadjaissainformatique/simu-win11-dz.git
   cd simu-win11-dz
   ```

2. **تثبيت الاعتماديات:**
   ```bash
   npm install
   ```

3. **تشغيل المحاكي في بيئة التطوير المكتبي:**
   ```bash
   npm start
   ```

4. **تشغيل حزمة الاختبارات الشاملة (Unit & Runtime Tests):**
   ```bash
   npm test
   ```

5. **بناء النسخ التنفيذية المحمولة (Portable Executables):**
   ```bash
   # بناء نسختي 32-بت و 64-بت
   npm run build:portable

   # بناء الحزمة الشاملة التلقائية
   npm run build:universal
   ```

## 📋 دليل الأستاذ السريع (Teacher's Quick Guide)

1. **التهيئة لأول مرة:**  
   عند تشغيل البرنامج لأول مرة دون وجود ملف `inf.dll`، ستظهر نافذة الإعداد الأولي لتحديد اسم الثانوية، اسم الأستاذ، الأفواج، وكلمة المرور الإدارية.
2. **الوصول للإعدادات لاحقاً:**  
   انقر على زر "حول البرنامج" أو أيقونة الإعدادات وأدخل كلمة المرور لتعديل الأفواج أو تحديث بيانات الموسم الدراسي.
3. **استخراج النتائج:**  
   في نهاية الجلسة، بعد استكمال سطح المكتب وتجربة الإقلاع، انقر على **تصدير PDF** لحفظ الشهادة الرسمية للتلميذ مباشرة في المجلد المخصص.
