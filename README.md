## 📌 نبذة عن المشروع (About The Project)

برمجية تعليمية تفاعلية ثنائية الأبعاد (**Pure 2D**) فائقة الخفة (~3 ميغابايت استهلاك ذاكرة)، صُممت خصيصاً لمخابر مادة **الإعلام الآلي** بالثانويات الجزائرية وفق منهاج **السنة الأولى ثانوي (1AS - جذع مشترك علوم وتكنولوجيا / جذع مشترك آداب)**، وضمن المقاربة بالكفاءات (Competency-Based Approach).

تهدف البرمجية إلى تمكين التلميذ من خوض التجربة العملية الكاملة لتثبيت وتهيئة نظام التشغيل **Windows 11** من الصفر وحتى سطح المكتب المستقل، عبر محاكاة محطة عمل فيزيائية حقيقية تشمل الوحدة المركزية، شاشة العرض، لوحة المفاتيح والفأرة، ووسائط التثبيت المختلفة، مع محاكاة إعدادات البيوس UEFI الحديثة وتأمين الخصوصية الرقمية وإدارة الأقراص، دون تعريض عتاد المخبر الحقيقي لأي خطر.

## 🖥️ البنية الفيزيائية لمحطة العمل (Physical Workstation Rig)

تتألف واجهة المحاكاة من محطة عمل ثلاثية الأبعاد البصرية (3-Column Layout) متصلة فيزيائياً من البداية إلى النهاية:

```
+---------------------------------------------------------------------------------------------------------+
|                                    شريط التتبع والتقييم العلوي (HUD Top Bar)                            |
+---------------------------------------------------------------------------------------------------------+
|                                                                                                         |
|   [العمود الأيسر]                     [العمود الأوسط]                          [العمود الأيمن]          |
|  الوحدة المركزية (Tower)        الشاشة الافتراضية الكبيرة (27" IPS)        رف وسائط التثبيت             |
|  - زر التشغيل اللمسي            - شاشة العرض الموحدة (المراحل 1 - 8)         - مفتاح Kingston 32GB USB   |
|  - قارئ أقراص DVD-RW            - شاشة OSD للاستعداد وحالة الإشارة          - قرص ويندوز 11 DVD ISO      |
|  - منافذ USB ومؤشرات LED       - حامل الشاشة المكتبي وقاعدته              - كابل شبكة مخبر PXE        |
|  - مؤشر كابل LAN Gigabit        - زر التكبير السريع [F10]                                               |
|  --------------------                                                                                   |
|  لوحة مفاتيح وفأرة مدمجة                                                                                |
|                                                                                                         |
+---------------------------------------------------------------------------------------------------------+
|                                  شريط المراحل والتقييم ومفاتيح المساعدة السفلية                          |
+---------------------------------------------------------------------------------------------------------+
```

1. **الوحدة المركزية (الجانب الأيسر)**: وحدة برجية واقعية تحتوي على:
   * **زر الطاقة اللمسي المضيء (Power Button)**: تشغيل الحاسوب يتم حصرياً بالضغط عليه (لا توجد أزرار طاقة اصطناعية على زجاج الشاشة).
   * **قارئ أقراص DVD-RW**: مزود بمؤشر قراءة وشارة توضح وجود القرص.
   * **منفذ USB 3.0 أمامي مخصص**: يستقبل مفتاح USB ويتيح نزعه فيزيائياً لكسر حلقة الإقلاع.
   * **مؤشرات LED ضوئية**: لمبة التشغيل الزرقاء ومؤشر نشاط القرص SSD الأحمر.
   * **لوحة مفاتيح وفأرة ضوئية**: مدمجة أسفل الوحدة المركزية لتعزيز الواقعية الإجرائية.
2. **الشاشة الافتراضية الكبيرة (الوسط)**: شاشة 27 بوصة عالية الوضوح:
   * تمثل **الشاشة الوحيدة المعتمدة طيلة المحاكاة من المرحلة 1 إلى 8** دون أي ازدواجية أو تكرار.
   * تعرض في البداية نافذة **OSD (DisplayPort - No Signal)** الواقعية عند إطفاء الوحدة المركزية، وتستجيب فوراً للتشغيل المادي.
   * مزودة بزر تبديل العرض للتبديل الفوري بين وضع محطة العمل ووضع الشاشة الموسعة [F10].
3. **رف وسائط التثبيت (الجانب الأيمن)**:
   * بطاقات تفاعلية أنيقة لمفتاح Kingston 32GB USB، قرص DVD ISO، وكابل شبكة PXE.

## 🎛️ نظام التحكم المزدوج في الشاشة (Dual Display Controls)

حرصاً على وضوح التجربة وتفادي أي التباس للمستخدم، يوفر التطبيق زرين مستقلين تماماً في الشريط العلوي:

* **🖥️ تكبير شاشة المحاكاة [F10]**:
  * التبديل بين **وضع محطة العمل الكاملة** (المكتب والبرج والرف) و**وضع تكبير الشاشة** (تمديد شاشة المحاكاة لتملأ 100% من مساحة العمل).
* **⛶ ملء نافذة التطبيق [F11]**:
  * التبديل بين **ملء شاشة البرنامج ككل** (OS Fullscreen) و**النافذة العادية المستعادة** لنافذة التطبيق على سطح مكتب الحاسوب.

## 🚀 طرق الاستخدام والتشغيل (How to Run)

تم تصميم هذا المشروع ليعمل بثلاث طرق مرنة تناسب كافة الظروف والمخابر:

### 1️⃣ التشغيل المباشر عبر المتصفح (Online - دون تحميل أي ملفات)
يمكن للأساتذة والتلاميذ تشغيل المحاكي التفاعلي كاملاً فوراً وبضغطة زر مباشرة عبر المتصفح (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari) على أي حاسوب أو جهاز لوحي:

🔗 **[اضغط هنا لتشغيل المحاكي مباشرة عبر GitHub Pages](https://atiklamine.github.io/education_win11_install_simulation/)**

---

### 2️⃣ التشغيل في مخابر الإعلام الآلي دون إنترنت (Offline Standalone EXEs)
للمؤسسات والمخابر غير المتصلة بشبكة الإنترنت، تتوفر حزم تنفيذية محمولة كاملة (Portable Standalone) مجمعة مسبقاً وتعمل مباشرة من الفلاش ديسك دون الحاجة لتثبيت مسبق أو صلاحيات مسؤول (Admin):

* 📥 **[تحميل الحزم المحمولة من قسم الإصدارات (GitHub Releases)](https://github.com/atiklamine/education_win11_install_simulation/releases)**:
  * **`Win11_Edu_Simulator_Universal_Auto.exe`** (~120 ميغابايت): **النسخة الشاملة الموصى بها**، تكتشف معمارية الجهاز تلقائياً وتشغل النسخة الأنسب (32-بت أو 64-بت).
  * **`Win11_Edu_Simulator_x64.exe`** (~62 ميغابايت): مخصصة للأجهزة الحديثة بمعمارية 64-بت (Windows 10/11 x64).
  * **`Win11_Edu_Simulator_ia32.exe`** (~59 ميغابايت): مخصصة للأجهزة القديمة والمحدودة الموارد بمعمارية 32-بت (Pentium / Celeron / Windows 7/8/10 32-bit).

---

### 3️⃣ التشغيل للمطورين عبر كود المصدر (Local Development)

#### المتطلبات الأساسية
* بيئة [Node.js](https://nodejs.org/) (الإصدار 16 أو أحدث).

#### خطوات التشغيل
1. استنساخ المستودع:
   ```bash
   git clone https://github.com/atiklamine/education_win11_install_simulation.git
   cd education_win11_install_simulation
   ```
2. تثبيت الحزم:
   ```bash
   npm install
   ```
3. تشغيل المحاكي المكتبي:
   ```bash
   npm start
   ```
4. تشغيل الفحص الآلي الشامل لجميع وحدات المحاكاة:
   ```bash
   npm test
   ```
5. تجميع النسخ المحمولة المستقلة:
   ```bash
   npm run build:portable
   npm run build:universal
   ```

## 🎯 المراحل التعليمية الثمانية (The 8 Pedagogical Phases)

| المرحلة | اسم المحطة التعليمية | الكفاءة المستهدفة والإجراء الواقعي |
| :---: | :--- | :--- |
| **01** | **تجهيز المحطة وتشغيل العتاد** | اختيار الوسيط من الرف الأيمن، التشغيل المادي عبر **زر الطاقة بالوحدة المركزية على اليسار**، ومقاطعة اختبار POST بالضغط السريع على `[F2 / Del]`. |
| **02** | **إعدادات البيوس (Aptio UEFI)** | تفعيل **TPM 2.0** و **Secure Boot**، ضبط وسيط التثبيت كإقلاع أول، والحفظ الإلزامي عبر مفتاح `[F10]`. |
| **03** | **المعايير الإقليمية واللغوية** | ضبط لغة العرض، تنسيق الوقت والعملة الجزائري (Algeria)، ولوحة المفاتيح المزدوجة (عربية 101/102 وفرنسية AZERTY). |
| **04** | **الترخيص والنسخة المتوافقة** | تجاوز إدخال المفتاح (I do not have a product key)، اختيار النسخة المدرسية (Windows 11 Pro Education)، واختيار التثبيت المخصص المتقدم (Custom). |
| **05** | **التجزئة والتهيئة بنظام NTFS** | تقسيم القرص غير المخصص (New) لإنشاء أقسام GPT الأربعة، والتهيئة الإلزامية للقسم الرابع الأساسي (Primary) بنظام **NTFS**. |
| **06** | **التثبيت ونزع الفلاشة فيزيائياً** | متابعة نسخ ملفات النظام، مقاطعة الإقلاع الثاني، ثم **النقر المباشر على مفتاح USB في منفذ الوحدة المركزية لنزعه فيزيائياً** لكسر حلقة التثبيت (Boot Loop). |
| **07** | **إعدادات OOBE والخصوصية** | إنشاء حساب محلي مستقل للمخبر المدرسي، وإلغاء تفعيل كافة خيارات التتبع الإعلاني السبعة (Turn All OFF) لضمان الأمان الرقمي. |
| **08** | **سطح المكتب والإقلاع المستقل** | استكشاف سطح مكتب Windows 11 الأصلي (خلفية Bloom، شريط المهام الأكريليكي الممركز)، وتنفيذ إعادة تشغيل مستقلة ونظيفة من SSD. |

## ✨ ميزات بيداغوجية وتنظيمية متقدمة (Advanced Features)

### 🔒 1. إدارة الإعدادات المشفرة للأستاذ (`inf.dll`)
* تشفير عالي الأمان بخوارزمية **AES-256-CBC** بمفتاح رقمي خاص.
* حماية لوحة تحكم الأستاذ (`Ctrl+Shift+S`) بكلمة مرور مشفرة.
* إمكانية تخصيص اسم المؤسسة، اسم الأستاذ، الموسم الدراسي، وقائمة الأفواج التربوية (مثل: `1AS-01`، `1AS-02`...).

### 🔠 2. التحقق من كتابة أسماء التلاميذ باللاتينية (French Names)
* مطابقة معايير الرقمنة الإدارية وتفادي أخطاء الحروف غير المتوافقة.
* دعم كامل للحروف الفرنسية وعلامات النبر (`é, è, ê, ë, à, â, î, ï, ô, ù, û, ç, æ, œ`).

### 📄 3. شهادة تقييم الكفاءة الرسمية (PDF Export)
* استخراج شهادة تقييم رسمية A4 تحمل الترويسة المعتمدة لـ **الجمهورية الجزائرية الديمقراطية الشعبية - وزارة التربية الوطنية**.
* تقييم مفصل مقسم على 4 كفاءات محورية (5.00 نقاط لكل كفاءة = المجموع /20.00).
* بطاقات متجاورة للعلامة والزمن المستغرق لحسم الترتيب عند تساوي النقاط (Tie-breaker).
* جدول معلل بالأخطاء العلمية المرتكبة مع التبرير البيداغوجي.
* **تسمية معيارية للفرز الفوري والتلقائي داخل مجلد الأستاذ**:  
  `[group]_[grade]_[time]_[lastname]_[firstname].pdf`  
  *(مثال: `1AS-01_18.50_00-14-32_BENALI_Yacine.pdf`)*

### 🌓 4. دعم الوضعين الفاتح والمظلم (Light / Dark Mode)
* زر تبديل سريع في شريط HUD يتوافق مع الإضاءة داخل المخبر مع حفظ التفضيل محلياً (`localStorage`).
