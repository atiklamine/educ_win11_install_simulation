## 📌 نبذة عن المشروع والرؤية البيداغوجية

يمثل هذا المحاكي حلاً تكنولوجياً وبيداغوجياً متكاملاً لمعضلة تدريس وحدة **«تثبيت وتهيئة نظام التشغيل»** المقررة في منهاج السنة الأولى ثانوي بالجزائر (جذع مشترك علوم وتكنولوجيا، وجذع مشترك آداب).

### 🎯 الأهداف التعليمية:
* **التدريب العملي الآمن:** خوض تجربة التثبيت خطوة بخطوة دون المخاطرة بحذف ملفات حقيقية أو إتلاف عتاد مخبر المؤسسة.
* **الواقعية الإجرائية:** محاكاة توصيل وفصل مفاتيح USB، الدخول الحقيقي إلى إعدادات الـ BIOS عبر لوحة المفاتيح، تقسيم الأقراص الصلبة بنظام NTFS، وإعداد حسابات المستخدمين.
* **التربية على المواطنة الرقمية وحماية البيانات الشخصية:** التركيز الصارم على إلغاء أذونات التتبع والخصوصية أثناء مرحلة الإعداد الأولي (OOBE).
* **التقييم المستمر والموضوعي:** حساب آلي للعلامة مع خصم الجزاءات وفق أخطاء معيارية، وتوليد تقرير تقييم رسمي برتبة التلميذ وزمن إنجازه بتنسيق PDF قابل للفرز الآلي.

## ✨ المميزات الرئيسية

* 🌐 **تشغيل أونلاين مباشر:** يعمل فوراً داخل أي متصفح ويب حديث دون أي تثبيت عبر [GitHub Pages](https://atiklamine.github.io/educ_win11_install_simulation/).
* 🚀 **فائق الخفة والأداء:** مكتوب بتقنيات الويب النقية (**HTML5 / Vanilla JavaScript / Pure CSS3 / SVG**) بدون أطر عمل ثقيلة، وبمعدل استهلاك ذاكرة لا يتجاوز **3 إلى 15 ميغابايت**.
* 🌐 **استقلالية تامة (100% Offline):** صفر استدعاء لمكتبات خارجية (Zero CDN). الخطوط والأيقونات والخلفيات كلها أصول محلية مدمجة تعمل دون إنترنت داخل المخابر المدرسية.
* 🖥️ **محطة عمل فيزيائية ثلاثية الأعمدة (3-Column Layout):** وحدة مركزية واقعية + شاشة 27 بوصة IPS + رف وسائط التثبيت المكتبي.
* ⌨️ **واقعية لوحة المفاتيح:** اشتراط الضغط على المفاتيح الحقيقية (`[F2]` أو `[Delete]` للدخول إلى BIOS، و `[F10]` للحفظ، والأسهم للتنقل).
* 🛡️ **نظام إعدادات مشفر للأستاذ (`inf.dll`):** حماية مشفرة بخوارزمية **AES-256-CBC** لإدارة أسماء الأساتذة، الثانويات، قوائم الأفواج، ونمط الحصة.
* 📄 **توليد شهادات PDF رسمية وفرز ذكي:** طباعة آلية لشهادة تقييم بيداغوجية تتضمن الترويسة الرسمية لوزارة التربية الوطنية واسم ملف ذكي يفرز التلاميذ بحسب الفوج، ثم العلامة، ثم سرعة الإنجاز.
* 🔄 **إدارة الطاقة والحالات الفيزيائية:** إمكانية تشغيل وإطفاء الحاسوب فيزيائياً عبر زر الطاقة اللمسي بالوحدة المركزية في أي مرحلة.
* 💻 **ثنائية المنصة والتوزيع:** يعمل مباشرة كملف تنفيذي محمول أحادي (**Portable .exe** لنواتي 32-bit و 64-bit) أو داخل أي متصفح حديث عبر الويب.

## 🖥️ البنية الفيزيائية لمحطة العمل (Workstation Rig)

تتألف بيئة المحاكاة من تصميم مريح وتفاعلي مقسم إلى 3 أعمدة متكاملة وظيفياً:

```
+---------------------------------------------------------------------------------------------------------+
|                                    شريط التتبع والتقييم العلوي (HUD Top Bar)                            |
+---------------------------------------------------------------------------------------------------------+
|                                                                                                         |
|   [العمود الأيسر]                     [العمود الأوسط]                          [العمود الأيمن]          |
|  الوحدة المركزية (Tower)        الشاشة الافتراضية الكبيرة (27" IPS)        رف وسائط التثبيت             |
|  - زر التشغيل اللمسي            - شاشة العرض الموحدة (المراحل 1 - 8)         - مفتاح Kingston 32GB USB   |
|  - قارئ أقراص DVD-RW            - شاشة OSD للاستعداد وحالة الإشارة          - قرص ويندوز 11 DVD ISO      |
|  - منافذ USB ومؤشرات LED       - حامل الشاشة المكتبي وقاعدته              - كابل شبكة مخبر PXE        |
|  - مؤشر كابل LAN Gigabit        - زر التكبير السريع [F10]                                               |
|  --------------------                                                                                   |
|  لوحة مفاتيح وفأرة مدمجة                                                                                |
|                                                                                                         |
+---------------------------------------------------------------------------------------------------------+
|                                  شريط المراحل والتقييم ومفاتيح المساعدة السفلية                          |
+---------------------------------------------------------------------------------------------------------+
```

### التحكم المزدوج في الشاشة (Dual Display Controls):
1. **🖥️ تكبير شاشة المحاكاة `[F10]`:** للتبديل بين وضع محطة العمل الكاملة (مع البرج والرف) ووضع شاشة العرض الموسعة (Focus Mode) لملء الشاشة بنوافذ التثبيت.
2. **⛶ ملء الشاشة الكلي `[F11]`:** للتبديل بين وضع ملء شاشة النظام (Full Screen) والنافذة المستعادة.

## 🔄 مراحل المحاكاة الثمانية (The 8 Phases)

| المرحلة | اسم المرحلة | المهمة البيداغوجية المطلوبة | المفهوم والهدف التعليمي |
| :---: | :--- | :--- | :--- |
| **1** | **تجهيز محطة العمل (POST)** | اختيار وسيط التثبيت، تشغيل الوحدة المركزية، والضغط الفوري على `[F2 / Del]` | فهم دورة الإقلاع الأولي للعتاد والتعرف على المنافذ والوسائط. |
| **2** | **إعدادات البيوس (BIOS/UEFI)** | ضبط تسلسل الإقلاع (Boot Order) لجعل الـ USB في الصدارة وحفظ الإعدادات | استيعاب وظيفة برنامج الـ BIOS وبروتوكول الإقلاع وتسلسل الأقراص. |
| **3** | **اللغة والإعدادات الإقليمية** | ضبط اللغة، تنسيق الوقت، ولوحة المفاتيح والضغط على Install Now | إتقان توطين النظام واختيار خيارات التثبيت المتوافقة. |
| **4** | **اتفاقية الترخيص وإصدار النظام** | قبول اتفاقية EULA واختيار تثبيت مخصص (Custom Advanced) | التفريق بين الترقية والتثبيت النظيف (Clean Install). |
| **5** | **تقسيم الأقراص الصلبة (NTFS)** | إنشاء قسم النظام، تهيئته بنظام ملفات NTFS، ومعاينة الأقسام المحجوزة | استيعاب مبدأ التقسيم الفيزيائي والمنطقي وأنظمة الملفات الحديثة. |
| **6** | **تثبيت ملفات النظام** | مراقبة مراحل التثبيت، وفصل مفتاح USB فور إعادة التشغيل لتفادي حلقة الإقلاع | فهم عملية نسخ وتوسيع الملفات والتعامل مع الإقلاع التلقائي للوسائط. |
| **7** | **الإعداد الأولي وتأمين الخصوصية** | تسمية الحاسوب، إنشاء حساب محلي، وتعطيل كافة أذونات التتبع والـ Telemetry | اكتساب مهارات الأمان الرقمي وتأمين خصوصية البيانات المدرسية. |
| **8** | **سطح المكتب والإنجاز النهائي** | تسجيل الدخول، استكشاف واجهة ويندوز 11، استعراض قائمة ابدأ، وتصدير التقرير | تقييم المكتسبات الختامية وتوليد كشف الدرجات الرسمي. |

## 📊 نظام التقييم البيداغوجي والشهادة الرسمية (PDF)

* **العلامة الكاملة:** تبدأ الجلسة برصيد **20.00 / 20.00**.
* **مصفوفة الجزاءات:** تُخصم النقاط عند ارتكاب أخطاء بيداغوجية حاسمة (مثل: نسيان وسيط التثبيت، فوات مهلة الدخول للبيوس، اختيار قرص غير مهيأ، ترك مفتاح USB موصولاً، أو ترك مفاتيح التتبع مفعلة).
* **بنك الأسئلة المرحلية:** اختبارات تقييمية قصيرة ومتوازنة الخيارات في كل مرحلة.
* **تصدير كشف العلامات PDF:** وثيقة رسمية تتضمن:
  - الجمهورية الجزائرية الديمقراطية الشعبية - وزارة التربية الوطنية.
  - اسم المؤسسة، السنة الدراسية، اسم الأستاذ، الفوج التربوي، واسم التلميذ.
  - العلامة المحصل عليها، زمن الإنجاز، وسجل المخالفات المرتكبة.
  - **تسمية ذكية للملف:** تُحفظ الملفات بصيغة ترتب التلاميذ آلياً أبجدياً وبحسب العلامة والزمن:
    ```
    1AS-01_18.50_00-15-20_BEN-AISSA_Yacine.pdf
    ```

## 🔐 نظام الإعدادات المشفرة للأستاذ (`inf.dll` & AES-256)

يوفر المحاكي نظام حماية قوي خاص بالأستاذ عبر اختصار لوحة المفاتيح:
> **اضغط `Ctrl + Shift + S` لفتح نافذة الإعدادات**

* يتم تخزين كافة البيانات داخل ملف `dist/inf.dll` محمي بتشفير **AES-256-CBC** مع Salt عشوائي لكل كلمة مرور ومفتاح مشتق برمجياً.
* يتيح للأستاذ:
  1. تخصيص اسمه واسم المؤسسة التعليمية والسنة الدراسية.
  2. إدارة وتحديث قائمة الأفواج التربوية المعتمدة (Classes/Groups).
  3. تفعيل أو إلغاء "نمط الامتحان الصارم" (30:00 دقيقة) لحساب التدريب الحر.
  4. فرض إدخال أسماء التلاميذ بالحروف اللاتينية/الفرنسية (A-Z) لمنع تلف ترميز ملفات PDF.

## 🖱️ إصلاحات تفاعل المؤشر وتجربة المستخدم (Prompt 6 Architecture)

تمت معالجة أدق تفاصيل أحداث المؤشر وتنسيق الطبقات (Stacking Context) جذرياً:

1. **حقول بيانات الحساب (OOBE Account Inputs):**
   - ربط كامل لكافة ملصقات الحقول `<label for="id">` لتمكين التفعيل المباشر بمجرد النقر على النص.
   - توسيع منطقة النقر (Hit Area) لتشمل الحاوية بالكامل بارتفاع $\ge 42\text{px}$ وبحاشية مناسبة للمس والفأرة.
   - فرض `cursor: text` و `pointer-events: auto` و `touch-action: manipulation`.
   - إصلاح مسار مفتاح `Tab` بعدم سرقة زر تفريغ كلمة المرور للتركيز، ودعم زر `Enter` للتنقل السلس والبدء الفوري.
2. **نافذة «مساعدة مرحلية» القابلة للسحب (Zero-Jump Draggable Modal):**
   - اعتماد التموضع الثابت `position: fixed` المباشر لإلغاء أي تشويه ناتج عن حاويات الأب.
   - حساب دقيق لـ `offsetX = clientX - rect.left` و `offsetY = clientY - rect.top` عند حدث `pointerdown`.
   - منع القفز اللحظي عند بدء السحب (`zero pixel jump`).
   - تقييد حركة النافذة داخل حدود الشاشة (Viewport Bounds Clamping) لمنع خروجها أو اختفائها خلف الشريط العلوي.
   - سلاسة مطلقة باستخدام `requestAnimationFrame` و `setPointerCapture`.

## 🌐 طرق التشغيل (أونلاين وفي مخابر غير متصلة)

### الخيار 1: التشغيل المباشر عبر الإنترنت (موصى به للمعاينة والتدريب السريع)
يمكنك فتح المحاكي مباشرة بالنقر على الرابط التالي في أي متصفح (Edge، Chrome، Firefox، Safari):
🔗 **[https://atiklamine.github.io/educ_win11_install_simulation/](https://atiklamine.github.io/educ_win11_install_simulation/)**

### الخيار 2: التشغيل دون إنترنت عبر الملفات التنفيذية المحمولة (Portable Executables)
مناسب لمخابر الإعلام الآلي بالثانويات غير المتصلة بالإنترنت:
1. توجه إلى صفحة [GitHub Releases](https://github.com/atiklamine/educ_win11_install_simulation/releases).
2. حمّل الملف المناسب لنظام المخبر:
   - `Win11_Edu_Simulator_x64.exe` لأنظمة 64-bit.
   - `Win11_Edu_Simulator_ia32.exe` للأجهزة القديمة 32-bit.
   - أو `Win11_Edu_Simulator_Universal_Auto.exe` لكشف المعمارية تلقائياً.
3. شغل الملف مباشرة بنقرة واحدة دون الحاجة إلى تثبيت (Zero-Install).

### الخيار 3: التشغيل للمطورين عبر سطر الأوامر (Node.js & Electron):
```bash
# 1. استنساخ المستودع
git clone https://github.com/atiklamine/educ_win11_install_simulation.git

# 2. الدخول إلى مجلد المشروع
cd educ_win11_install_simulation

# 3. تثبيت الاعتماديات
npm install

# 4. تشغيل المحاكي عبر Electron
npm start
```

## 🧪 حزمة الاختبارات والفحوصات الآلية (Automated Testing & CI)

يتضمن المشروع 12 حزمة اختبار مؤتمتة تغطي أدق تفاصيل المحاكي بنسبة نجاح **100%**:

```bash
npm test
```

1. `test_simulator.js`: التحقق من وجود الملفات الأساسية وتوازن خيارات الأسئلة.
2. `test_electron_runtime.js`: اختبار إقلاع Electron واستجابة واجهات العرض على دقات 1024x768 و 1366x768 و 1920x1080.
3. `test_six_modifications.js`: فحص منفذ الـ USB، التشفير، الطبقات، وبطاقات التقييم.
4. `test_modifications_7_8.js`: فحص استقلالية الأصول، عزل خط Segoe UI، وسلامة DLL.
5. `test_theme_and_french_names.js`: التحقق من تبديل الثيمات وإلزام الأسماء بالحروف اللاتينية.
6. `test_user_reported_fixes.js`: التحقق من معالجة البلاغات وإشعارات الأفواج.
7. `test_layout_3column_workstation.js`: التحقق من سلامة البنية ثلاثية الأعمدة.
8. `test_strict_no_auto_execution.js`: التأكد الصارم من عدم وجود أي انتقال تلقائي بدون تدخل التلميذ.
9. `test_session_reset.js`: اختبار تصفير الجلسات وإعادة ضبط البيانات بالكامل.
10. `test_prompt4_customization.js`: التحقق من تخصيص المسارات، خلفيات الـ Bloom، وأيقونات الـ SVG.
11. `test_prompt5_investigation.js`: فحص مرونة حسابات OOBE، زر التشغيل اللمسي، وفلترة البحث.
12. `test_prompt6_pointer_and_cleanup.js`: فحص إصلاحات قفز نافذة المساعدة، ارتباط الحقول، وتكامل المستودع.

## 📦 النشر والتوزيع (Packaging & Deployment)

### 1. بناء النسخ المحمولة (Portable Executables):
```bash
# بناء نسخة 64-bit المحمولة
npm run build:portable64

# بناء نسخة 32-bit المحمولة (لتشغيلها على أجهزة المخابر القديمة)
npm run build:portable32

# بناء النسخة الشاملة التلقائية (Universal Auto)
npm run build:universal
```

### 2. النشر التلقائي على الويب (GitHub Pages):
المشروع مهيأ بالكامل للنشر الآلي على **GitHub Pages** عبر مسار العمل المدمج `.github/workflows/deploy-pages.yml`. يعمل ملف `index.html` في الجذر وملف `.nojekyll` على تشغيل المحاكي تلقائياً وبأقصى سرعة على الويب.
